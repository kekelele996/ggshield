### Added

- New `ggshield config trace [KEY]` command to troubleshoot configuration
  resolution. For every key it shows the value provided by each layer
  (default, global/local/custom config file, `.env` file, environment
  variable, command line option, credential store), which layer wins, which
  lower values are overridden, and which layers conflict. Sensitive values
  such as API keys are masked and the credential store is never read. A tip
  line indicates which single layer (and which single key) a change should
  be written to.
